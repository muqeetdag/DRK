Performance selects only governors exposed by your installed kernel and uses modest I/O read-ahead. Balanced returns the governor to schedutil rather than leaving it wherever the last profile put it. Every profile states its full intent, so no knob is left behind at the previous value.

THERMAL GUARD

Backs off before the kernel has to

The guard never disables thermal protection. While the performance profile is active it watches the hottest thermal zone: at 43 °C it returns the governor to schedutil, at 47 °C it also drops read-ahead to 128 KiB, and below 40 °C it hands performance back. Your chosen profile is never rewritten — the override is temporary and recorded separately.

APPLIED-STATE AUDIT
Did it actually stick?
Read-only scan of every cpufreq governor, frequency ceiling, block read-ahead node, animation scale and thermal zone the active profile targets. A node the kernel refuses to expose is reported, not silently skipped — and any policy driven past its own hardware ceiling is flagged, whoever set it.
What this module will not do
It does not bypass banking protections, falsify integrity, defeat ads or paid features, modify games, or disable thermal protection. Those requests are unsafe, unreliable, or violate other software’s rules.

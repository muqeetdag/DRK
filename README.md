# DRK

Two projects live here:

* **DRKMUQEET** — Magisk device-tuning console for begonia (see `DRKMUQEET/README.md`).
* **nyx/** — NYX, a white-label dark-mode Instagram shell (LSPosed module + companion console). One `white-label.json` drives the name, palette, icons and feature defaults, and `nyx/build.sh` produces a signed sideload-ready APK. Prebuilt APKs are in `nyx/apk-out/`.
